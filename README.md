Sistema de Control de Acceso a Laboratorio

Descripción
Aplicación en Java que permite gestionar usuarios y controlar el acceso a un laboratorio técnico mediante registros de entrada y salida.

Funcionalidades
- Registro de usuarios
- Control de entradas y salidas
- Validaciones de acceso
- Historial por usuario
- Cálculo de tiempo total dentro del laboratorio

Tecnologías
- Java
- Swing
- Archivos .txt

Estructura
- entidades
- accesodatos
- logicanegocio
- presentacion
